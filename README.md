## 📂 Projetos em Destaque

### 🛒 [Loja API REST](https://github.com/vitordiamantino/java-loja-api)
> API RESTful completa para gerenciamento de produtos de uma loja virtual

- CRUD completo com Spring Boot 3 e Java 21
- Persistência com Spring Data JPA + banco H2
- Validação de dados com Bean Validation (`@Valid`)
- Arquitetura em camadas: Controller → Service → Repository
- Endpoints: listagem, busca por ID, categoria e nome, criação, atualização e exclusão

`Java 21` `Spring Boot` `JPA` `H2` `Maven` `REST API`

---

### 🏦 [Sistema Bancário](https://github.com/vitordiamantino/java-sistema-bancario)
> Sistema bancário desktop demonstrando os 4 pilares da Orientação a Objetos

- Contas Corrente e Poupança com herança e polimorfismo
- Depósito, saque, transferência e extrato com histórico
- Simulação mensal (rendimento de poupança / taxa de conta corrente)
- Exceções customizadas (`SaldoInsuficienteException`, `ContaNaoEncontradaException`)
- Interface gráfica com Java Swing

`Java 21` `Swing` `OOP` `Herança` `Polimorfismo` `Exceções`

---

### 🧮 [Calculadora Desktop](https://github.com/vitordiamantino/java-calculadora)
> Calculadora com visual dark inspirado no iOS/macOS

- Operações básicas, porcentagem e apagar dígito
- Histórico de cálculos
- Suporte completo a teclado
- Separação de responsabilidades: lógica (`Calculadora.java`) separada da UI (`CalculadoraUI.java`)

`Java 21` `Swing` `OOP` `MVC`
